# product-report-assemble

Скилл для Codex и Claude, который собирает месячный или квартальный продуктовый отчёт Lamoda из заметок, таблиц, скриншотов и черновиков команд. Подходит для полного отчёта и для отдельного блока.

**[Скачать ZIP для установки](https://github.com/ruslanovich/product-report-assemble/raw/refs/heads/main/product-report-assemble.zip)** · [Посмотреть правила скилла](product-report-assemble/SKILL.md) · [Скачать шаблон PPTX](https://github.com/ruslanovich/product-report-assemble/raw/refs/heads/main/product-report-assemble/assets/product-report-template.pptx)

В ZIP входят правила сборки и редактируемый шаблон с 14 слайдами-образцами. Пакет работает без MCP, хуков и установочных скриптов. Примеры для настройки можно добавить после скачивания.

## Установка

| Среда | Что сделать | Как вызвать |
|---|---|---|
| Codex на компьютере | Распакуйте ZIP. Скопируйте папку `product-report-assemble` целиком в `~/.agents/skills/`. Если каталога ещё нет, создайте его. | Выберите скилл из списка или напишите `$product-report-assemble`. |
| Claude Code на компьютере | Распакуйте ZIP. Скопируйте ту же папку целиком в `~/.claude/skills/`. | Напишите `/product-report-assemble`. |
| Claude в браузере или приложении | Включите выполнение кода и создание файлов. В **Customize → Skills → Create skill → Upload a skill** загрузите ZIP и включите скилл. | Попросите применить скилл `product-report-assemble`. |

Установка на уровне пользователя делает скилл доступным из разных локальных чатов и проектов. Для Claude Cowork и облачных сессий используйте установку через аккаунт. Доступ к диску зависит от среды выполнения. При работе в облаке прикладывайте файлы к запросу или добавляйте в пакет профиль и подходящий шаблон. Для Codex Cloud пакет должен быть доступен в самой среде, например в `.agents/skills/` нужного репозитория.

## Настройка по своим примерам

Скилл готов работать сразу. Если есть утверждённые отчёты, приложите PPTX или укажите путь к одному файлу либо папке. Подойдёт и PDF. Назовите основной образец, если в файлах разное оформление.

> Примени product-report-assemble. Изучи приложенные PPTX как примеры оформления и структуры. Сохрани предпочтения в моей копии скилла для следующих отчётов. Для рабочих слайдов ориентируйся прежде всего на месячный пример.

Локально профиль сохраняется в `references/personal-profile.md` внутри установленной папки. Для установки через аккаунт приложите сам ZIP вместе с примерами, попросите вернуть обновлённый архив и загрузите его в **Customize → Skills**. При желании можно сохранить в пакете и свой очищенный PPTX. Если пользуетесь обоими локальными приложениями, перенесите профиль и выбранный шаблон в обе копии.

## Сборка отчёта

Приложите заметки, таблицы, скриншоты или черновики команд. В локальной сессии можно указать пути вместо вложений. Укажите период, команды и результат, который хотите получить.

> Примени product-report-assemble. Собери блок доставки за октябрь в редактируемом PPTX. Таблица KPI и скриншоты приложены, заметки лежат в указанной папке. Покажи план и факт, основные запуски и ближайшие задачи, если они подтверждены.

> Примени product-report-assemble. Собери квартальный отчёт из приложенных блоков. Проверь, где команды говорят об одном результате, и сохрани разные ракурсы там, где они важны.

Встроенный шаблон находится в `assets/product-report-template.pptx`. Вручную можно открыть его копию, оставить нужные слайды-образцы и заменить поля в квадратных скобках. На слайде динамики замените учебный ряд реальными данными.
